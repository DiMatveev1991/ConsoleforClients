# ConsoleForClients — разовое обогащение клиентов из сервиса ИНН

Консольное приложение (.NET 8). Разово прогоняет **московских клиентов с принадлежностью
к КО** (`Clients.AgentCode = 304`, `Clients.Client_Department = 1`) с непустым ИНН через
сервис ИНН (`contragents.major-express.ru`) и заполняет **только пустые** поля в
`ClientsPayers`.

## Что заполняется (только если поле пустое)

| Поле БД                        | Источник из сервиса                                   |
|--------------------------------|-------------------------------------------------------|
| `ContragentTypeId`             | `contragentType` (строка → ID через `ContragentTypeMap`) |
| `OGRN`                         | `ogrn`                                                 |
| `KPP`                          | `kpp` головной записи (`branch = MAIN`) — если у клиента КПП нет |
| `GeneralDirectorPositionName`  | `managment.post` — **только если должность пустая**    |
| `GeneralDirector`              | `managment.fio` — заполняется вместе с должностью       |

Если у клиента **должность уже заполнена**, ФИО и должность не перезаписываются.

## Логика запроса к сервису

- КПП у клиента есть (`cp.KPP` не пусто) → запрос `inn + kpp`, берётся запись с этим КПП.
- КПП нет → запрос только по `inn`. Если ответ **неоднозначный** (не ровно 1 запись) —
  клиент **пропускается**.

## Перед запуском — заполнить `appsettings.json`

1. `ConnectionStrings:Express` — строка подключения к БД `Express`.
2. `ContragentService:BaseUrl` и `:Path` — адрес и маршрут эндпоинта из swagger
   (по умолчанию `/api/contragent`; вызов идёт как
   `{BaseUrl}{Path}?inn=...&kpp=...&showMainContragent=true`).
3. `Enrichment:ContragentTypeMap` — маппинг типа контрагента. При старте берётся из
   справочника `dbo.Types_ContragentTypes` (`LEGAL=1`, `INDIVIDUAL=2`), этот блок —
   запасной вариант, если таблица недоступна.

ИНН с потерянным ведущим нулём (в БД лежит короче 10/12 знаков) при вызове сервиса
автоматически дополняется нулём слева.

Опционально: `Concurrency` (одновременных запросов), `MaxClients` (лимит на запуск, `0` = все).

## Запуск

```bash
dotnet run -c Release
```

По завершении печатается статистика (успешно / не успешно с разбивкой) и пишется
подробный лог `enrichment-log.txt`.
